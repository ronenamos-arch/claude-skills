מה זה עושה

מסייע לחשב תרחישי שכר ולהסביר רכיבי תלוש, מס הכנסה, ביטוח לאומי והפרשות. יש לבדוק את שנת המס והטבלאות המצורפות לפני כל שימוש, ולא להפיק תלוש מחייב מהערכה בלבד.

מה אומרים לקלוד

אין פקודות ללמוד. אחרי ההתקנה פשוט כותבים לקלוד משפט כמו:

  • "חשב הערכת ברוטו לנטו"

מה צריך שיהיה מותקן

מהלמה / הערה
Python ונתוני העובדנדרשים שנת מס, שכר, נקודות זיכוי ותנאי הפרשות; יש לוודא שהטבלאות מעודכנות.

לתשומת לבך: הסקיל הועתק מהמקור ברישיון MIT. לא בוצע אימות מקצועי של נוסחאות, שיעורים, ספים או הוראות דין בקובצי המקור. יש לאמת נתונים עדכניים ולקבל בדיקת רו״ח לפני פעולה כספית, דיווח או שליחה למערכת חיה.

התקנה בהדבקה אחת

פותחים את Claude Code, מדביקים את הבלוק הבא, והוא מתקין הכול לבד:

הי קלוד! התקן לי בבקשה את הסקיל "חישובי שכר בישראל" (israeli-payroll-calculator).
1. זהה את מערכת ההפעלה שלי ואת התיקייה ~/.claude/skills/ (ב-Windows: C:\Users\<user>\.claude\skills\). צור אותה אם אינה קיימת.
2. הורד את החבילה: https://ronenamos-arch.github.io/claude-skills/dl/israeli-payroll-calculator.tar.gz
3. חלץ ממנה את התיקייה skills/israeli-payroll-calculator אל ~/.claude/skills/israeli-payroll-calculator. אם כבר קיים סקיל בשם הזה - שאל אותי לפני שאתה דורס.
4. בדוק אם מותקנים אצלי: Python ונתוני העובד. אם חסר משהו - תגיד לי בדיוק מה להתקין ותציע להתקין בעצמך.
5. הסבר לי בקצרה איך מפעילים - למשל שאני פשוט אומר: "חשב הערכת ברוטו לנטו".
מעדיף טרמינל? (Git Bash / Mac / Linux) 
curl -fsSL https://ronenamos-arch.github.io/claude-skills/install.sh | bash -s -- israeli-payroll-calculator

או הורדה ידנית של החבילה וחילוץ אל ~/.claude/skills/.
