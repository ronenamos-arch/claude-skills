מה זה עושה

עוזר לתכנן או לארגן מחדש סביבת עבודה לפי Interpretable Context Methodology: תיקייה לכל תפקיד, הפרדה בין חומר קבוע לתוצרים וקובצי הקשר קצרים שמכוונים את הסוכן. מתאים לתהליכים חוזרים, מאגרי ידע ומיפוי מערכות. בשינוי סביבה קיימת מציעים תוכנית ומבקשים אישור לפני העברה.

מה אומרים לקלוד

אין פקודות ללמוד. אחרי ההתקנה פשוט כותבים לקלוד משפט כמו:

  • "בנה סביבת עבודה בשיטת ICM"

מה צריך שיהיה מותקן

מהלמה / הערה
סוכן שיכול לקרוא ולכתוב קבציםלסקריפטי האינדוקס והבדיקה המצורפים נדרש Python 3. לא נדרשת מסגרת סוכנים חיצונית.

לתשומת לבך: יש לגבות קבצים קיימים ולאשר תוכנית העברה לפני ארגון מחדש. התקנת הסקיל אינה מפעילה את הסקריפטים שלו.

התקנה בהדבקה אחת

פותחים את Claude Code, מדביקים את הבלוק הבא, והוא מתקין הכול לבד:

הי קלוד! התקן לי בבקשה את הסקיל "ארכיטקט סביבת עבודה ICM" (icm-architect).
1. זהה את מערכת ההפעלה שלי ואת התיקייה ~/.claude/skills/ (ב-Windows: C:\Users\<user>\.claude\skills\). צור אותה אם אינה קיימת.
2. הורד את החבילה: https://ronenamos-arch.github.io/claude-skills/dl/icm-architect.tar.gz
3. חלץ ממנה את התיקייה skills/icm-architect אל ~/.claude/skills/icm-architect. אם כבר קיים סקיל בשם הזה - שאל אותי לפני שאתה דורס.
4. בדוק אם מותקנים אצלי: סוכן שיכול לקרוא ולכתוב קבצים. אם חסר משהו - תגיד לי בדיוק מה להתקין ותציע להתקין בעצמך.
5. הסבר לי בקצרה איך מפעילים - למשל שאני פשוט אומר: "בנה סביבת עבודה בשיטת ICM".
מעדיף טרמינל? (Git Bash / Mac / Linux) 
curl -fsSL https://ronenamos-arch.github.io/claude-skills/install.sh | bash -s -- icm-architect

או הורדה ידנית של החבילה וחילוץ אל ~/.claude/skills/.
