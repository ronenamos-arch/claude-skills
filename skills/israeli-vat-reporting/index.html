מה זה עושה

מסייע להכין סיכומים, לבחון פערים ולהבין מקרים מיוחדים כמו עסקאות פטורות או בשיעור אפס. אינו מחליף בדיקה מקצועית ואינו מגיש דוח לרשות המסים ללא חיבור והרשאה נפרדים.

מה אומרים לקלוד

אין פקודות ללמוד. אחרי ההתקנה פשוט כותבים לקלוד משפט כמו:

  • "הכן סיכום מע״מ לתקופת הדיווח"

מה צריך שיהיה מותקן

מהלמה / הערה
Python ונתוני עסקאות ותשומותיש לוודא תקופת דיווח, שיעורי מס וכללים עדכניים לפני שימוש בפלט.

לתשומת לבך: הסקיל הועתק מהמקור ברישיון MIT. לא בוצע אימות מקצועי של נוסחאות, שיעורים, ספים או הוראות דין בקובצי המקור. יש לאמת נתונים עדכניים ולקבל בדיקת רו״ח לפני פעולה כספית, דיווח או שליחה למערכת חיה.

התקנה בהדבקה אחת

פותחים את Claude Code, מדביקים את הבלוק הבא, והוא מתקין הכול לבד:

הי קלוד! התקן לי בבקשה את הסקיל "הכנה ובדיקה של דוחות מע״מ" (israeli-vat-reporting).
1. זהה את מערכת ההפעלה שלי ואת התיקייה ~/.claude/skills/ (ב-Windows: C:\Users\<user>\.claude\skills\). צור אותה אם אינה קיימת.
2. הורד את החבילה: https://ronenamos-arch.github.io/claude-skills/dl/israeli-vat-reporting.tar.gz
3. חלץ ממנה את התיקייה skills/israeli-vat-reporting אל ~/.claude/skills/israeli-vat-reporting. אם כבר קיים סקיל בשם הזה - שאל אותי לפני שאתה דורס.
4. בדוק אם מותקנים אצלי: Python ונתוני עסקאות ותשומות. אם חסר משהו - תגיד לי בדיוק מה להתקין ותציע להתקין בעצמך.
5. הסבר לי בקצרה איך מפעילים - למשל שאני פשוט אומר: "הכן סיכום מע״מ לתקופת הדיווח".
מעדיף טרמינל? (Git Bash / Mac / Linux) 
curl -fsSL https://ronenamos-arch.github.io/claude-skills/install.sh | bash -s -- israeli-vat-reporting

או הורדה ידנית של החבילה וחילוץ אל ~/.claude/skills/.
