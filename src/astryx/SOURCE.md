# Source

Official Astryx skill by Meta Platforms, Inc. (MIT), copied unchanged from https://github.com/meta/astryx (plugins/astryx/skills/astryx/SKILL.md). Official install: `npx skills add https://github.com/meta/astryx --skill astryx`. The skill points the agent to the `astryx` CLI (`npm i -g @astryxdesign/cli`), which holds the actual docs, components and templates. Astryx is in beta.
